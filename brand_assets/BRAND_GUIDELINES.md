# Second Shift Ops — Brand Guidelines

**Package status:** AI-readable brand system, based on the approved brand direction from the referenced conversation.

**Asset status:** No final vector logo assets were supplied in the source conversation. Logo geometry, clear-space rules, minimum sizes, iconography specifications, and interaction details below are proposed standards until the master vectors are approved.

## 1. Brand foundation

| Field | Approved direction |
|---|---|
| Brand | Second Shift Ops |
| Domain | secondshiftops.co |
| Primary tagline | **Less grunt work. More great work.** |
| Brand promise | Intelligent workflow automation for businesses with better things to do. |
| Positioning | Eliminate repetitive work, reclaim time, and improve operational efficiency. |
| Personality | Intelligent, confident, pragmatic |
| Visual style | Modern, minimal, premium |
| Voice | Direct, conversational, understated |
| Emotional benefit | Freedom from tedious work |
| Functional benefit | Increased operational efficiency |

### Core idea

Every business has two kinds of work: the work that moves it forward and the work that gets in the way. Second Shift Ops automates the emails, data entry, reports, and repetitive processes that quietly consume the day, so people can return to the work they started the business to do.

## 2. Messaging system

### Primary message

**Less grunt work. More great work.**

### Supporting statement

Intelligent workflow automation for businesses with better things to do.

### Preferred call to action

**Reclaim your time**

### Secondary call to action

**Explore our solutions**

### Messaging principles

- Lead with the business benefit, not the complexity of AI.
- Talk about efficiency, reclaimed time, and freedom from repetitive tasks.
- Make automation feel practical, capable, and human.
- Avoid positioning the brand as a night-shift service or implying that customers should work longer hours.
- Avoid exaggerated claims, hype, jargon, and generic “AI magic” language.

## 3. Logo system

### Approved concept

The mark is an S-shaped system of two interconnected workflow arrows. It represents delegation, continuous workflows, automation, and work moving from one step to the next.

### Lockups

Use these conceptual variations when final vectors are created:

1. Primary horizontal lockup: symbol plus “Second Shift Ops” wordmark.
2. Stacked lockup: symbol above or beside a two-line wordmark.
3. Standalone symbol: the interconnected S-shaped arrows.
4. Simplified favicon: the most legible reduced symbol.

### Clear space — proposed standard

Define **X** as 25% of the height of the S symbol. Maintain at least **X** of unobstructed space around every logo variation. No text, borders, images, or other elements may enter this exclusion zone.

### Minimum sizes — proposed standard

| Variation | Digital minimum | Print minimum |
|---|---:|---:|
| Horizontal logo | 180px wide | 45mm wide |
| Stacked logo | 120px wide | 30mm wide |
| Standalone symbol | 24px wide | 8mm wide |
| Simplified favicon | 16px wide | Not applicable |

Validate these minimums against the final vector assets before treating them as production requirements.

### Logo use

- Use white lettering on dark backgrounds.
- Use navy lettering on light backgrounds.
- Keep the mark proportional and optically balanced.
- Never stretch, rotate, recolour, outline, bevel, or add shadows to the logo.
- Do not recreate the mark by tracing the illustrative SVG from the prior conversation; use approved master vectors when available.

| Electric Teal | `#18C5C9` | Primary accent, key actions, brand emphasis |

| Off White | `#F5F7FA` | Light surfaces, reversed text |
| Dark Teal | `#087C80` | Accessible light-theme accent, links, outlined actions |
| Secondary Text | `#667085` | Body text on light surfaces |

### Interaction colours

| Token | Hex | Role |
|---|---|---|
| Hover Teal | `#42D6D9` | Hover state for primary actions |
| Pressed Teal | `#10A9AD` | Pressed/active state |
| Disabled Dark | `#293140` | Disabled controls on dark surfaces |

### Recommended distribution

Use approximately 60% navy, 25% off white, 10% teal, and 5% supporting colours. Teal should draw attention to important actions rather than dominate every element.

## 6. Iconography — proposed standard

Use the [Lucide icon library](https://lucide.dev/) as the standard website icon system. Its restrained linework complements the brand without adding unnecessary visual complexity.

| Property | Specification |
|---|---|
| Style | Outline with rounded line caps |
| Stroke width | 1.75–2px |
| Standard size | 24px |
| Feature size | 32–48px |
| Primary colour | Electric Teal |
| Container radius | 12px |
| Container background | Electric Teal at 8–12% opacity |

Avoid cartoon robots, excessive sparkles, emoji-style graphics, and generic AI imagery. The brand should feel like a serious operational partner, not an AI novelty.

## 7. Button system — proposed standard

Buttons should feel confident and functional, with modest rounded corners rather than exaggerated pill shapes.

### Button labels

- Primary: **Reclaim your time**
- Secondary: **Explore our solutions**
- Tertiary: **See how it works**
- Example disabled state: **Book a consultation**

### Button specifications

| Property | Standard | Hero |
|---|---:|---:|
| Height | 48px | 56px |
| Corner radius | 8px | 8px |
| Horizontal padding | 24px | 24px |
| Font | Inter 600 | Inter 600 |
| Transition | 150–200ms | 150–200ms |
| Text | `#0B1020` | `#0B1020` |
| Background | `#18C5C9` | `#18C5C9` |
| Hover background | `#42D6D9` | `#42D6D9` |
| Pressed background | `#10A9AD` | `#10A9AD` |

Use dark text on teal buttons for contrast. On light backgrounds, use dark teal for outlined buttons and text links. Provide a visible focus state and preserve keyboard accessibility.

| Element | Specification |
|---|---|

| Desktop grid | 12 columns |
| Spacing system | Multiples of 8px |
| Section spacing | 80–120px desktop; default 96px |
| Card radius | 16px |
| Input radius | 8px |
| Card borders | Subtle, low contrast |
| Shadows | Minimal or none |
| Animation | Subtle, workflow-inspired motion |

### Suggested page flow

1. Hero: tagline, supporting statement, and primary CTA.
2. Problem: repetitive operational work that slows the business down.
3. Solutions: workflow automation explained in plain language.
4. Proof: outcomes, examples, or customer evidence.
5. Process: a simple path from manual work to automated work.
6. CTA: reclaim time and explore a consultation or solution.

## 9. Implementation notes for AI tools

- Treat the primary tagline, brand promise, personality, palette, and typography as approved brand direction.
- Treat logo clear space, minimum sizes, iconography, button dimensions, layout values, and interaction states as proposed standards pending final design review.
- Never generate a final logo asset from the illustrative SVG in the source conversation.
- Prefer existing design tokens in `design-tokens.json` and variables in `brand.css` over new one-off values.
- Use semantic HTML, accessible contrast, visible focus states, and reduced-motion support.
- Keep copy direct, practical, and benefit-led.
