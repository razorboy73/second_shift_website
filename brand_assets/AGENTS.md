# Second Shift Ops — AI Implementation Instructions

Use this folder as the source of truth for Second Shift Ops brand implementation.

## Priority rules

1. Preserve the approved tagline exactly: **Less grunt work. More great work.**
2. Preserve the brand promise: **Intelligent workflow automation for businesses with better things to do.**
3. Use the existing values in `design-tokens.json` and `brand.css` before introducing new colours, type styles, radii, spacing, or motion values.
4. Keep language direct, conversational, understated, and benefit-led.
5. Explain automation through business outcomes: less repetitive work, reclaimed time, and improved efficiency.

## Asset rules

- Final vector logo assets are not included yet.
- Do not treat an illustrative logo diagram as a final production logo.
- Do not redraw, trace, stretch, rotate, recolour, outline, bevel, or shadow the logo.
- When final vectors are supplied, place them in `logos/` and update the asset status in `design-tokens.json`.

## Visual rules

- Headings use Montserrat; body and interface text use Inter.
- Use Lucide for interface icons with restrained outline styling and rounded line caps.
- Use Electric Teal for emphasis and actions; do not make every element teal.
- Use modest 8px button corners and 16px card corners.
- Prefer minimal shadows and subtle workflow-inspired motion.
- Maintain visible focus states and support reduced motion.

## Proposed versus approved

Approved: brand name, tagline, promise, positioning, personality, voice, core palette, and typography direction.

Proposed pending design review: logo clear space, minimum logo sizes, iconography details, button measurements, website layout values, and interaction states.

## Required checks

- Verify exact tagline and promise before shipping copy.
- Check responsive layouts at mobile and desktop widths.
- Check text and control contrast.
- Check keyboard navigation and focus visibility.
- Confirm that any logo file is an approved vector asset before using it in production.
